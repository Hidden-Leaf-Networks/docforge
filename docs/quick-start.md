# Quick Start Guide

Get from zero to your first generated PDF in under five minutes.

## Prerequisites

- Python 3.10 or later
- pip

## Installation

```bash
pip install docforge
```

If you need Word document support:

```bash
pip install docforge[word]
```

For all optional formats (Word, Excel):

```bash
pip install docforge[all]
```

## Generate Your First PDF

Create a file called `hello.py`:

```python
from docforge import DocumentGenerator, Theme

theme = Theme(
    brand_name="My Company",
    primary="#3B82F6",
    footer_text="Generated by My Company",
)

gen = DocumentGenerator(theme=theme)

gen.create_pdf(
    "my-first-report.pdf",
    title="Quarterly Update",
    content="## Highlights\n\nRevenue grew **18%** this quarter.\n\n- Launched two new products\n- Expanded into three new markets\n- Hired 12 team members",
    metadata={
        "author": "Jane Doe",
        "organization": "My Company",
        "document_type": "report",
    },
)

print("Done! Check my-first-report.pdf")
```

Run it:

```bash
python hello.py
```

This produces a professional PDF with:

- A branded cover page with the document type, title, author, and date
- A themed accent divider in your primary color
- Parsed markdown body with headings, bold text, and bullet lists
- A footer with your brand name and page numbers

## Generate a Simple PDF (No Cover Page)

For lighter documents that don't need a full cover page:

```python
gen.create_simple_pdf(
    "status-update.pdf",
    title="Weekly Status",
    content="## Completed\n\n- Shipped feature X\n- Fixed bug Y\n\n## Next Week\n\n- Start feature Z",
    metadata={"author": "Jane Doe"},
)
```

## Generate a Word Document

```python
gen.create_word(
    "report.docx",
    title="Monthly Report",
    content="## Summary\n\nAll targets met.",
    metadata={
        "author": "Jane Doe",
        "organization": "My Company",
    },
)
```
